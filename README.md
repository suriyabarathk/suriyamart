# SuriyaMart

Spring Boot 3.5.6 + Java 17 + MySQL online shopping mart.

## Run
1. Start MySQL.
2. Open a terminal in this folder.
3. Run:

`mvn org.springframework.boot:spring-boot-maven-plugin:3.5.6:run`

4. Open http://localhost:8082/

## Database
Database: `suriya_mart`
MySQL user: `root`
MySQL password: `admin` (change application.properties if yours differs).

## Project features
Buyer shopping, search, categories, cart, checkout, orders and reviews API; seller product/order management; admin user/order management.
